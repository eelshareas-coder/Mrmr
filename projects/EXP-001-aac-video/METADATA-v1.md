# EXP-001 — Publication Metadata v1

## Title
هل AAC يعني جهاز؟ الحقيقة أبسط من كده

## Description
هل AAC يعني جهاز أو تطبيق واحد؟ مش بالضرورة.

في هذا الفيديو نشرح بشكل مبسط أن التواصل المعزز والبديل (AAC) يشمل طرقًا متعددة، وقد يكمّل الكلام الموجود أو يوفر طريقة بديلة للتواصل. اختيار الوسيلة المناسبة يختلف حسب احتياجات الشخص وسياقه.

المحتوى تعليمي عام، وليس تشخيصًا أو تقييمًا فرديًا أو خطة علاج.

# EXP-001 — Measurement Plan v1

## Purpose
Measure whether the prototype is understandable, accessible, and operationally useful without confusing audience metrics with clinical evidence.

## Baseline
Before publication record:
- channel/subscriber baseline
- recent comparable-video baseline when available
- publication date/time
- video length
- title and thumbnail version
- format

## Audience metrics
At a fixed review interval record:
- impressions
- click-through rate when available
- views
- average view duration
- average percentage viewed
- watch time
- retention curve
- comments/questions
- returning-viewer signals when available

## Accessibility/quality signals
- caption error count
- audio issues
- unreadable text reports
- confusing scene transitions
- repeated viewer questions indicating unclear wording

## Scientific integrity
Never use views, likes, retention, or comments as proof that AAC is clinically effective.

## Learning questions
1. Did viewers understand that AAC is broader than one device?
2. Did viewers understand that AAC may supplement speech or provide an alternative mode?
3. Did the evidence boundary remain understandable?
4. Which scene generated confusion?
5. Which accessibility issue needs correction?

## Experiment discipline
Change one major production variable at a time where practical. Preserve prior versions and their metrics.

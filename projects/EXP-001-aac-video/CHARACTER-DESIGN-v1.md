# EXP-001 — Character Design v1

## Status
Design direction approved for production planning. Visual reference image is not yet approved.

## Character ID
CHR-001 — نور

## Role
Original fictional recurring protagonist for educational AAC stories.

## Character concept
نور شخصية كرتونية أصلية وهادئة وفضولية، تظهر في مواقف تواصل يومية. لا تُقدَّم كشخصية "مشكلة" تحتاج إلى إصلاح، ولا تُربط بتشخيص محدد داخل الحلقة.

The story uses نور to demonstrate that communication can happen through more than one mode.

## Communication portrayal
نور may use:
- spoken words when useful
- gesture
- picture/communication board
- writing/text
- speech-generating device

Important: the character may switch between modes according to the scene. The visual language must not imply that one mode is universally superior.

## Visual identity
- Original 2D/2.5D cartoon.
- Warm, simple, readable silhouette.
- Medium-length dark hair.
- Comfortable everyday clothing with a simple recurring accent shape.
- Expressive face without exaggerated disability stereotypes.
- Neutral, respectful body language.
- No medical equipment unless a specific scene requires it.
- No direct resemblance to an existing copyrighted character, studio style, or living artist.

## Production requirements
Create one master character reference containing:
1. front view
2. 3/4 view
3. side view
4. neutral expression
5. curious expression
6. happy/relieved expression
7. thinking expression
8. hand/arm pose suitable for gesture
9. holding a simple picture board
10. interacting with a generic speech-generating device

## Consistency anchors
Keep these fixed across episodes:
- face shape
- hairstyle
- clothing silhouette
- recurring accent shape
- approximate proportions
- eye style
- line/illustration language

## Accessibility
- Expressions must remain understandable without relying only on color.
- Important communication tools must remain visually distinguishable at mobile size.
- Avoid flashing or overly fast facial/hand motion.
- Do not portray speech as the only marker of success.

## Prompt baseline
Use this prompt family for the visual reference:

"Original fictional 2D/2.5D educational cartoon character named Nour, warm curious personality, respectful everyday appearance, clear readable silhouette, expressive but natural face, medium-length dark hair, simple comfortable clothing with one recurring geometric accent, cinematic soft lighting, clean original illustration language, front/three-quarter/side character reference sheet, neutral and curious expressions, gesture pose, holding a simple communication picture board, interacting with a generic speech-generating device, educational storytelling, accessible mobile-first composition, no logos, no copyrighted characters, no imitation of any named studio or living artist, no photorealism."

## Approval gate
Do not generate the full episode asset set until CHR-001 has a stable approved visual reference.

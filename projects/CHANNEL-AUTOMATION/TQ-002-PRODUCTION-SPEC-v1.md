# TQ-002 — Production Specification v1

## Goal
Produce a 60–90 second original educational cartoon episode without introducing claims outside the verified package.

## Pipeline
ASSETS → VOICE → ANIMATION → EDIT → CAPTIONS → DESCRIPTIVE TRANSCRIPT → QA

## Scene rules
1. Hook must state the question without answering it prematurely.
2. The "DONE" stamp is a deliberate misconception, not an accessibility judgment.
3. The counterexample must make clear that captions accurately represent speech/audio while important visual information may remain unrepresented.
4. The evidence scene must distinguish captions, visual description, and descriptive transcripts.
5. The final takeaway must remain media-context dependent.

## Audio
- Clean dialogue.
- Moderate pacing.
- Pauses between concepts.
- No background sound that masks speech.

## Visual
- Original Noor and original graphics.
- No third-party footage required.
- Avoid flashing or distracting motion.
- Do not rely on color alone to communicate the checklist.

## Deliverables
- master video
- caption file
- descriptive transcript
- thumbnail
- metadata package
- rights provenance record
- QA report

## Gate
Production may create drafts. PUBLISH_READY remains blocked until all deliverables and QA gates pass.

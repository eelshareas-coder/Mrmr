# Production Pipeline v1

## Pipeline
IDEA -> RESEARCH -> EVIDENCE CARD -> CONTENT BRIEF -> SCRIPT -> STORYBOARD/SCENE PLAN -> ASSETS -> ANIMATION/EDIT -> ACCESSIBILITY -> SCIENTIFIC/SAFETY REVIEW -> METADATA -> PUBLISH PACKAGE -> PUBLISH -> MEASURE -> LEARN

## Definition of Ready
An episode can enter production only when:
- evidence question is defined
- evidence card exists
- content brief is approved
- scope/safety boundaries are known
- rights assumptions are documented

## Definition of Done
An episode is publish-ready only when:
- final export is verified
- captions are checked
- assets are rights-safe
- scientific/safety review passes
- accessibility review passes
- metadata is approved
- measurement record is prepared

## Stop conditions
Stop and return to review when:
- evidence changed materially
- an asset has unclear rights
- a claim became stronger during editing
- accessibility was lost during cinematic treatment
- private/sensitive material entered the project
- platform adaptation changes factual meaning

## Versioning
Use episode ID + artifact type + version.
Example: EXP-001-SCRIPT-v1.

## Learning loop
Every published episode creates a learning record. Audience metrics can inform communication and production decisions, but cannot establish clinical effectiveness.

# Publishing Metadata Role

## Role
**Metadata & Publishing Copy Lead**

This role owns the publication-facing text for every episode:
- title
- description
- hashtags
- keywords/tags where the platform supports them
- source/disclosure text
- platform-specific copy variants

## Workflow
1. Read the final approved script and evidence boundaries.
2. Identify the single viewer-facing promise of the episode.
3. Draft 3 title candidates without making unsupported promises.
4. Select the production title after review against clarity and search intent.
5. Write the description with:
   - one-sentence hook
   - concise episode summary
   - scope/disclosure when relevant
   - sources when required
6. Generate a small, relevant hashtag set.
7. Create platform variants without changing the factual meaning.
8. Run the metadata through the final review gate before publishing.

## Rules
- Never use engagement bait that misrepresents the evidence.
- Never claim treatment, cure, guaranteed outcomes, or individual suitability without evidence and scope.
- Do not turn comments, views, or retention into proof of clinical effectiveness.
- Hashtags must describe the actual episode; avoid unrelated trending tags.
- Titles should be clear before they are clever.
- The metadata writer may improve discoverability, but cannot alter scientific meaning.
- Final metadata must match the approved script and evidence card.

## Deliverable template
For every episode, produce:
- Final title
- Alternate title candidates
- Description
- Hashtags
- Keywords/tags
- Sources/disclosure
- Platform variants
- Metadata review status

## Ownership
The Metadata & Publishing Copy Lead is responsible for copy quality. Scientific/safety review remains a separate gate and cannot be bypassed by the metadata role.

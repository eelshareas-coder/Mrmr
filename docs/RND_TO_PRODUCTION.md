# R&D to Production

## Pipeline
Research -> Evidence Card -> Content Brief -> Script -> Prototype -> Review -> Export -> Publish -> Measure -> Learn.

## Evidence card
- Claim/question
- Best available sources
- Population/context
- Strength and limitations
- Uncertainty
- Safe wording
- Source links
- Review date

## Production experiment
Every experiment should define:
- hypothesis
- one major change
- baseline
- audience
- success/learning signal
- observation period
- result
- next action

## Quality gates
1. Knowledge
2. Safety
3. Production quality
4. Rights and privacy
5. Publish readiness

## Free-first production
Prefer free/open-source tools and lawful open-license assets when they meet quality requirements. Paid tools are optional, never a requirement for scientific quality.

## Accessibility
Prioritize:
- readable captions
- clear speech
- sufficient visual contrast
- logical visual hierarchy
- concise on-screen text
- descriptive context where useful

# Cross-Platform Publishing

## Purpose
Adapt one approved episode into platform-native versions without changing its scientific meaning.

## Content source
The canonical source is the approved episode package in Mrmr. Platform variants are derivatives.

## Adaptation map
YouTube: full episode + Shorts.
Instagram: Reel + caption + optional carousel.
Facebook: Reel/video + concise description.
TikTok: short vertical cut + concise caption.

## Non-negotiable rule
Platform adaptation may change duration, framing, hook placement, caption density, and copy length. It may not strengthen, weaken, or reinterpret an evidence claim.

## Required derivative record
For each derivative record:
- source episode ID
- platform
- aspect ratio
- duration
- title/caption
- hashtags
- caption status
- asset rights status
- publication status
- version ID
- publication URL after publishing
- measurement link/record

## Reuse
Reuse is allowed when the asset license/ownership permits it and the derivative preserves accessibility and context.

## Publishing states
draft -> reviewed -> scheduled -> published -> measured -> learned

## Failure handling
If a platform version introduces confusing context, accessibility loss, rights uncertainty, or misleading copy, pause that derivative without blocking the approved source episode.

# Free-First Production Stack

## Principles
- Use free tools first.
- Verify current licensing and export limits before committing to a workflow.
- Never use pirated software or bypass paid restrictions.
- Keep source/project files organized so the workflow can be migrated later.

## Categories
### Research
- PubMed / PMC
- Europe PMC
- DOAJ
- Google Scholar
- Official guidance

### Writing and planning
- Markdown
- GitHub Issues
- Local/offline notes where appropriate

### Video/audio
Prefer established free/open-source editors and audio tools when they meet the project's quality needs. Evaluate each tool for:
- licensing
- watermark/export limits
- captions
- audio controls
- proxy/media management
- stability
- hardware requirements

### Graphics
Prefer open-license/public-domain assets and simple original graphics.

### Analytics
Use first-party platform analytics before buying third-party dashboards.

## Rule
"Free" is a cost property, not a quality guarantee. Every tool is evaluated by output quality, rights, privacy, reliability, and sustainability.

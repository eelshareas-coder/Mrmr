# Cinematic Cartoon Series Bible v1

## Series architecture
Each episode is a standalone story inside one shared original cartoon universe.

## Episode structure
1. Cold open
2. Question/problem
3. Character interaction
4. Visual explanation
5. Evidence boundary
6. Resolution
7. Closing continuity cue

## Recurring characters
Character IDs are created only after an original design is approved.
Each character needs:
- role in story
- personality/function
- visual reference
- communication traits
- accessibility considerations
- continuity notes

No copyrighted characters or direct imitation of another creator's distinctive style.

## Environment system
Use a reusable set of original locations:
- home
- classroom
- therapy/learning setting when educationally appropriate
- community/public setting
- abstract explanation space

Each environment gets a visual reference and reuse status.

## Story engine
A future episode proposal should include:
- question
- audience
- evidence card
- misconception/problem
- visual metaphor
- character action
- takeaway
- evidence boundary
- accessibility plan
- metadata intent

## Continuity
Continuity can appear through characters, environments, transitions, sound motifs, title cards, and recurring visual language.

Continuity must never force a scientific claim into a story that the evidence does not support.

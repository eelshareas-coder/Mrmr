# YouTube Operating System

## Purpose
Turn each approved episode into a repeatable YouTube publishing workflow while feeding measurement back into R&D.

## Channel structure
- Channel identity and About text
- Series playlists
- Episode archive
- Shorts derivatives
- Source/disclosure pattern
- Caption standard
- Thumbnail standard
- Analytics baseline

## Episode workflow
Research approval -> production approval -> accessibility review -> metadata review -> publish package -> upload/schedule -> verify live page -> record baseline -> measure -> learning note.

## Required publish package
- Final video export
- Thumbnail
- Title
- Description
- Hashtags
- Keywords/tags when supported
- Captions/subtitles
- Sources/disclosure text
- Playlist/series placement
- Publication date/time
- Version identifier

## Thumbnail rules
Original artwork only, readable on mobile, one clear visual idea, no unsupported medical promise, no deceptive imagery, and consistent series identity.

## YouTube quality gate
Before upload confirm:
- correct final export
- captions checked
- title matches approved meaning
- description matches evidence boundary
- sources/disclosure included when required
- thumbnail is rights-safe
- no private data
- playlist is correct
- measurement record is ready

## Measurement
Track available metrics such as impressions, CTR, views, average view duration, average percentage viewed, watch time, retention, comments/questions, and returning-viewer signals.

These are audience/product metrics, not evidence of clinical effectiveness.

## R&D feedback
Every episode produces:
1. performance record,
2. accessibility issues,
3. recurring viewer questions,
4. production issues,
5. evidence/communication lessons,
6. next experiment hypothesis.

Change one major production variable at a time where practical.

# Video R&D

## دورة التطوير
Idea → Prototype → Test → Analyze → Revise → Review → Publish

## اختبار الفيديو
نسجل مؤشرات مثل:
- نسبة بدء المشاهدة.
- الاحتفاظ بالمشاهد.
- نقاط الخروج.
- التفاعل.
- التعليقات والأسئلة المتكررة.
- جودة الصوت والترجمة.
- وضوح الدعوة للإجراء.

## البحث عن الفشل
عند ضعف فيديو، ننشئ فرضيات قابلة للاختبار بدل لوم الجمهور:
- هل العنوان لا يشرح الفائدة؟
- هل أول ثوانٍ غير واضحة؟
- هل الشرح طويل؟
- هل اللغة صعبة؟
- هل توجد معلومات كثيرة في فيديو واحد؟
- هل الترجمة أو الصوت يعيقان الفهم؟

ثم نختبر نسخة محسنة ونقارن النتائج.

## التنفيذ
كل فيديو ناجح في الاختبار يتحول إلى:
- نسخة نهائية.
- عنوان ووصف.
- ترجمة.
- صورة مصغرة.
- مصادر عند الحاجة.
- سجل تغييرات.

## السلامة
المحتوى المتعلق بالصحة النفسية أو الإعاقة تعليمي عام، وليس تشخيصًا أو علاجًا فرديًا. الحالات التي تتطلب تقييمًا أو تدخلًا متخصصًا تُحال إلى مختص مناسب.

# MRMR — Public Production

المستودع العام هو استوديو الإنتاج والنشر.

## نطاقه
- الفيديوهات ومخرجات الإنتاج.
- الصور والرسومات.
- الموسيقى والمؤثرات المسموح باستخدامها.
- قوالب المونتاج والهوية البصرية.
- النصوص والسيناريوهات المعدة للنشر.
- أدوات الإنتاج الخفيفة.
- مواد ومنتجات المحتوى المخصصة لفيسبوك ويوتيوب.

## تنظيم الإنتاج
content/ → media/ → projects/ → publish/

- content/ — الأفكار والسكريبتات والنصوص.
- media/video/ — مخرجات الفيديو.
- media/images/ — الصور والرسومات.
- media/audio/ — الموسيقى والمؤثرات.
- projects/ — ملفات تعريف مشاريع الإنتاج.
- publish/ — الحزم الجاهزة للنشر.
- docs/ — قواعد الإنتاج والترخيص.

## قاعدة مهمة
لا نضع بيانات خاصة بالأطفال أو الأسر، أو سجلات حالات فردية، أو كلمات مرور، أو مفاتيح API، أو أسرار تشغيلية في هذا المستودع.

الوسائط الكبيرة يفضل تخزينها في تخزين ملفات/وسائط مناسب وربطها بالـ metadata داخل Git بدل تحميل كل الملفات الثنائية إلى Git.
